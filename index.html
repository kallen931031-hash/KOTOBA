使用說明與程式測試

單字資料為同資料夾的 vocab.json（JSON 陣列）。從網站開啟會自動載入；直接開啟 HTML 時，可用「匯入 JSON」選取檔案。匯入會替換基礎字庫，並保留此瀏覽器新增的單字。字庫、新增標記及最近一次已交卷的結果會保存在這個瀏覽器。匯出 JSON 只包含單字，可用來備份或搬移字庫。搜尋只篩選表格；考試使用完整字庫。PNG 會依目前的篩選結果產生，完成後可儲存或開啟圖片。

填空會忽略前後空白，並將片假名轉為平假名比對；長音、促音與大小假名仍須正確。四選一優先取用字庫中不同的讀音，不足時使用備用假名。每題等分，未作答算錯，總分四捨五入。新加入 JSON 的單字會從第二次載入起自動標記，也可手動清除標記。

程式分為 DATA（載入、驗證與去重）、EXAM LOGIC（洗牌、選項、計分）、UI（畫面、儲存與下載）三區。所有功能不依賴外部套件。內建測試可隨時執行，也可在網址加上 ?test=1 自動執行。
